### 🧠 Resource-Constrained SPARQL Query Generation from Natural Language

**Master's Thesis | TU Chemnitz | 2026**

**Master's Thesis | TU Chemnitz | 2026**

Research and development of a system for generating SPARQL queries from natural language using Large Language Models in a resource-constrained computing environment.

The project explored the integration of a locally deployed LLM with Knowledge Graph technologies while considering the computational limitations of the hosting server.

**Key technologies:** Python, LLMs, SPARQL, Knowledge Graphs, DBpedia.
